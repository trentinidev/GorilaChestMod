# Changelog

## 1.0.0

Primeira versão, para Valheim 1.0.7.

- Craft e upgrade na bancada usando os itens dos baús dentro do raio configurado.
- Custo de construção com martelo, enxada e cultivador também pago pelos baús,
  com opção para desligar.
- Lista de receitas, números de "tenho / preciso" e botão de craft passam a
  contar o conteúdo dos baús.
- Seus itens são gastos primeiro, depois os baús, do mais perto para o mais longe.
- Respeita as regras de acesso do jogo: raio, privacidade do baú, guard stone e
  baú aberto por outro jogador.
- Client side. Funciona em servidor dedicado sem mod no servidor.
